# 寒水 · HANSHUI SPACE

陆寒水的个人博客，记录文字、阅读与随想。

[访问博客](https://hanshui.space/)

## 博客功能

- 首页诗词、文章索引与独立文章阅读页。
- 文章发布日期、修改时间、RSS 订阅与站点地图。
- 首页和文章留言区，支持 Google 登录、退出及留言审核。
- 首页主图、文章封面、背景、页眉横幅与正文图片。
- 视觉工作台，支持图片透明度、模糊、面板磨砂、裁切焦点及强调色调整。
- 桌面与手机适配、阅读进度，以及适量的悬停和进入动画；支持减少动态偏好。
- Supabase 定期只读保活。

视觉以编辑式网格、大字号、灰白底色与朱红几何构成为主，保持简约与清晰的阅读体验。

博客基于 Hugo 构建，使用 Supabase 提供登录与留言服务，通过 Cloudflare Pages 发布。
